## Description ##

SureFeedback Client Site is a WordPress plugin that lets you collect note-style feedback from your client's websites and sync them with your SureFeedback parent project.

## Installation ##

1. Upload the plugin files to the /wp-content/plugins/ directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Settings -> SureFeedback to configure the plugin options
