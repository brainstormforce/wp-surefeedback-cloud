Collect note-style feedback from your client's websites and sync them with your SureFeedback parent project.

== Description ==

First Release - SureFeedback Client is a modern WordPress plugin that revolutionizes how you collect and manage client feedback.

The SureFeedback Client plugin enables seamless collection of sticky note-style feedback directly from client websites, automatically synchronizing with your SureFeedback parent project for centralized management.

**Why Choose SureFeedback Client?**

SureFeedback transforms the traditional feedback process by allowing clients to point, click, and leave targeted comments directly on their websites. No more lengthy email chains or confusing feedback - clients can show exactly what they mean with visual, contextual notes.

== Installation ==

1. Go to `Plugins -> Add New` and search for SureFeedback Client
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to `Settings -> SureFeedback` to configure the plugin options
4. Connect to your SureFeedback account to start collecting feedback

== Frequently Asked Questions ==

= What is the purpose of this plugin? =

The purpose of this plugin is to make it simple to get targeted feedback from clients on web designs. All you have to do is install the SureFeedback Client plugin and let your clients select areas of your design to add their own comments. Everything is tracked within the plugin and synced with your SureFeedback parent project.

= Do I need a SureFeedback account? =

Yes, you need a SureFeedback parent project to connect this client plugin to. The plugin syncs all feedback data with your centralized SureFeedback dashboard.

= What are the technical requirements? =

The plugin requires WordPress 4.7 or higher and PHP 7.4 or higher. It has been tested up to WordPress 6.8.

= Can I customize the branding? =

Yes, the plugin includes white label support, allowing you to customize the branding to match your agency or client requirements.
